# Technical Details

## Article Editing

- **`src/app/main-pages/edit-article/edit-article.component.ts:27-39`** — Component state with reactive form (header, category, subCategory) and AngularEditor for rich text body with image upload support.
- **`src/app/main-pages/edit-article/edit-article.component.ts:110-135`** — `onSaveClick()` builds Article object and calls `articleService.saveArticle()` for Firestore CRUD (POST for new, PATCH for updates).
- **`src/app/main-pages/edit-article/edit-article.component.ts:163-196`** — `resizeAndCropImage()` resizes cover images to base64 (480x270) with vertical centering; also used for inline body images via `insertImage()`.
- **`src/app/main-pages/image-drop/image-drop.component.ts:36-44`** — Drag-drop handler that converts dropped files to base64 and resizes to 480x270 before emitting to parent.
- **`src/app/services/article.service.ts:271-330`** — `saveArticle()` performs Firestore REST API calls (POST to collection for new articles, PATCH to document for updates) with `lastUpdated` timestamp set to `toISOString()`.
- **No content validation** — Only UI enablement via FormControl `dirty` state; no required field validators or content length checks.

## Article Rendering

- **`src/app/interfaces/article.ts:24-27`** — `ArticleState` enum defines PREVIEW (Firestore) vs ACTIVE (static JSON files) dual-state architecture.
- **`src/app/components/article/article.component.ts:117-140`** — `ngOnInit()` loads article from Firestore (PREVIEW) or JSON files (ACTIVE) via `articleService.getArticle()`, applies sanitization and YouTube link conversion.
- **`src/app/components/article/article.component.ts:142-175`** — `convertYoutubeLinks()` regex-based transformer converts YouTube URLs to embedded iframes and wraps naked URLs in anchor tags with `target="_blank"`.
- **`src/app/services/article.service.ts:146-172`** — `loadJsonArticle()` fetches from `assets/data/articles/{articleId}.json` (static files generated by GH Actions).
- **`src/app/services/article.service.ts:126-144`** — `getArticle()` caches articles by state in memory, returns PREVIEW from Firestore or ACTIVE from JSON files.
- **`src/app/services/article.service.ts:113-124`** — `isOld()` compares PREVIEW vs ACTIVE `lastUpdated` timestamps to flag stale cached articles.

## Article Search

- **`src/app/main-pages/search/search.component.ts:10-11`** — Uses embeddings index (`assets/index/article-embeddings.json`) and calls Cloud Functions endpoint for query embedding via OpenAI `text-embedding-3-small`.
- **`src/app/main-pages/search/search.component.ts:116-149`** — `performSearch()` embeds query (with localStorage caching), computes cosine similarity against all article embeddings, returns top 10 results.
- **`src/app/main-pages/search/search.component.ts:183-191`** — `cosineSimilarity()` vector math for semantic search scoring.
- **`.github/workflows/scripts/generate-index.js:19-25`** — `generateEmbedding()` calls OpenAI API to create 1536-d embeddings from article header + body + lastUpdated timestamp.
- **`.github/workflows/scripts/generate-index.js:28-78`** — Main `generateEmbeddings()` processes all JSON articles, strips HTML, merges into incremental index file.
